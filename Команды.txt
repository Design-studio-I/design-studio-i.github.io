Золотое правило работы с Decap CMS:

Если ты поработал в админке в браузере — первым делом на компьютере делай git pull. Только после этого начинай править код в VS Code или другом редакторе. 

git push --set-upstream origin main 

Эта команда не просто отправит файлы, но и «склеит» твою папку с GitHub навсегда, чтобы в следующий раз можно было писать просто git push. 

Нужен пост наверху? Ставишь pinned: true
